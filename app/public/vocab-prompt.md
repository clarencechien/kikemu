# kikemu 場景包 prompt(貼給外部有「搜尋 + 思考」的 LLM)

> 用法:把下面「---- 從這裡開始複製 ----」到結尾整段貼給 ChatGPT / Gemini / Claude 等
> **開了網路搜尋與深度思考**的模型,把 `{{主題}}` 換成你要去的地方或要聽的導覽
> (例:`佐渡 尾畑酒造 学校蔵 酒蔵見学`)。手上有官網網址、導覽影片說明欄,
> 貼在 `{{補充資料}}`(沒有就刪掉那段)。把它回的 md 存成檔案,到管理頁「匯入 md」上傳。
>
> 韓文導覽:把「読み(全角ひらがな)」那欄改成「한글 읽기」,`lang: ja` 改成 `lang: ko`。

---- 從這裡開始複製 ----

你要幫一個「日語導覽 → 即時中文字幕」的 App 做**語音辨識自訂詞表**。
這份詞表會餵給語音辨識引擎(Speechmatics 的 additional_vocab),目的是讓它
**聽到這些詞時寫對字**。辨識引擎最常錯的是:專有名詞寫成同音的別字(真野鶴 → 真鶴、
尾畑 → 緒方)、行業術語寫成常見詞(日本酒度 → 日本酒道 / 日本酒うどん)。

## 請這樣做

1. **用網路搜尋**:官方網站(含商品/展示/導覽頁)、觀光協會、百科、新聞報導。
   主題相關的每個頁面都看一下,不要只看首頁。
2. 收集導覽中**實際可能被唸出來**的詞:
   - 主題本身的正式名稱、常見略稱
   - 建築・設施・展區名
   - 人名(創辦人、職人、歷史人物)
   - 地名(含小地名、路名、車站)
   - **商品名・品牌名・系列名**(酒款、菓子、工藝品等,個別商品也要)
   - 祭典・活動・儀式名
   - **行業術語**:這個領域的導覽會講、一般人不熟、辨識引擎容易聽錯的詞
     (酒藏例:日本酒度、精米歩合、山田錦、純米大吟醸、生酛、杜氏)
   - 周邊的店名・商店街名
3. 每個詞給**讀音**(全角ひらがな)。有多種唸法就都列,用「、」分隔。
   **不確定就留空,絕對不要猜**——讀音錯會讓辨識變更差;只有表記沒有讀音仍然有用。
4. **不要收**:日常詞(お酒、料理、建物)、整句話、說明文字。
5. 數量 50~300 條;寧可精準,不要湊數。

## 輸出格式(嚴格照做,只輸出這份 md,前後不要加任何說明)

```
---
kikemu-pack: 1
lang: ja
name: (主題的日文正式名稱)
alias: (給台灣使用者看的中文短名,10 字內)
---

| 表記 | 読み | 種別 | 出典 |
|---|---|---|---|
| 尾畑酒造 | おばたしゅぞう | 社名 | https://... |
| 真野鶴 | まのつる | 銘柄 | https://... |
| 日本酒度 | にほんしゅど | 専門用語 | |

## 出典
- https://...
- https://...
```

- 「表記」= 導覽字幕上應該出現的寫法(日文原文,不要翻成中文)
- 「読み」= 全角ひらがな,多個用「、」分隔;不確定留空
- 「種別」= 社名 / 施設 / 人名 / 地名 / 銘柄 / 商品 / 行事 / 専門用語 / 店名 之一
- 「出典」= 你在哪個網址看到這個詞(可留空);文末「出典」列出你實際看過的網址
